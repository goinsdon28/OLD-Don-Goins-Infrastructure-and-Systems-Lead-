Overview

Built a production-reporting pipeline that transformed raw warehouse-control-system log data into structured SQL Server reporting and SSRS dashboards.

Architecture

  • WCS Logs → Parsed with Bash tools such as grep and awk
  • Structured export → Loaded into SQL Server
  • SQL views → Normalization, aggregation, and comparison logic
  • SSRS → Operational reporting layer

Key Technique

15-minute interval bucketing was used to normalize event timestamps into consistent reporting windows.

DATEADD(MINUTE, DATEDIFF(MINUTE, 0, EVENT_DT)/15*15, 0)

Validation & Troubleshooting

The reporting work required comparing source data across systems, investigating duplicate or regenerated events, and validating whether differences represented real production activity or data-quality problems.

Why This Matters

The project demonstrates end-to-end ownership from raw production data through extraction, database transformation, validation, and usable operational reporting.
